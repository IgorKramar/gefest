# Concepts

Shared domain vocabulary for this project — entities, named processes, and status concepts with project-specific meaning. Seeded with core domain vocabulary, then accretes as ce-compound and ce-compound-refresh process learnings; direct edits are fine. Glossary only, not a spec or catch-all.

## Процесс и ворота

### Сторож
Автоматическая проверка (CI-check, валидатор), падающая при рассинхроне артефактов — например, сгенерированных метаданных с их источником. Легитимен, только когда у каждого класса проверяемых участников есть честный путь до зелёного внутри их периметра; сторож, ловящий невозможность вместо забывчивости, порождает обходы.

### Дверь
Намеренно открытая точка расширения без обязательства её реализовать: заготовка в схеме, флаг, зарезервированное поле. Дверь снабжается названным триггером открытия и, где уместно, бюджетом — порогом использования, за которым решение пересматривается целиком, а дверь не дрейфует в умолчание.

### Интерим-регламент
Временное сужение автономии участников, записанное как принятая цена решения вместе с условием снятия. Сужение без условия снятия считается дырой в автономии, а не регламентом.

## Доставка

### Указание
Единица инбокса, адресованная исполнителю: команда владельца или сообщение агенту. Вид `command` требует доставки и эскалации; вид `message` ждёт естественного пробуждения адресата без эскалации доставки — но непрочитанное дольше порога эскалируется алертом владельцу.

### Каузальный delivered
Статус доставки указания, подтверждённый активностью, каузально связанной с вручением, а не фактом записи или пульсом процесса: при вручении в простое — любой новой активностью потока, при вручении посреди хода — только активностью, начавшейся после завершения инструмента, работавшего в момент вручения. Ошибочные события доставку не подтверждают.

## Брокер ресурсов

### Комплект брокера
Набор, который раннер готовит контейнеру задачи при старте: рабочая копия кода, чистая dev-БД клоном шаблона, ограниченные токены, переменные выданных ресурсов, набор аутентификации и памяти роли. Секреты живут только у раннера и умирают вместе с контейнером; комплект — единственный канал, которым исполнитель получает ресурсы.
