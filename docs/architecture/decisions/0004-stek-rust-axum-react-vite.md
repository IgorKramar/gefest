# ADR-0004: Стек Гефеста — Rust (axum/tokio/sqlx) + React 19/Vite 8; Bun как toolchain

- **Date**: 2026-08-20
- **Status**: Accepted
- **Authors**: Игорь (владелец); light-цикл D-1
- Артефакты цикла: `../research/2026-08-20-stek-gefesta*.md`

## Context

Стек был унаследован молча от agent-dashboard (observe O-1); ADR-0002 («с нуля») делает выбор бесплатным ровно сейчас. Владелец: «наиболее современный, легковесный и быстрый; как насчёт rust?». Discovery выяснил: нагрузка тривиальна (один пользователь, единицы агентов, чистый I/O) — «быстрый» рантайм не сила; но **биллинг сервера — по потреблению ресурсов** (новое ограничение C-С1): idle-RAM резидентного процесса — прямые деньги. Rust/TS/Python — родные языки владельца. Research (август 2026): axum 0.8.x/tokio/sqlx 0.9 — зрелый мейнстрим; MCP-SDK на Rust официальный и зрелый (rmcp 3.1.4, ~21 млн загрузок); pgvector — официальный крейт; idle-RAM порядком Rust (~5–30 МБ) < Go (×2–4) < Python (60–150+ МБ/воркер); Vite 8 стабилен (Rolldown), консенсус для SPA — React 19 + TanStack Router/Query + Tailwind 4; Bun (1.3.x, принадлежит Anthropic) зрел как install/test/dev-toolchain, как бандлер React-SPA уступает Vite.

## Decision

- **Бэкенд (раннер-супервизор + панель): Rust** — axum 0.8 (HTTP/SSE/WebSocket) + tokio (супервизия `tokio::process`) + sqlx (Postgres, FTS) + rmcp (MCP-recall) + pgvector-crate (дверь ADR-0003). Один бинарь; статика фронта раздаётся из него — лишних резидентных процессов нет.
- **Фронтенд: React 19 + TypeScript + Vite 8 + TanStack Router + TanStack Query + Tailwind CSS 4**; SSE — нативный EventSource + инвалидация Query.
- **Bun — toolchain** (bun install / bun test / dev-скрипты); сборка — Vite 8; как прод-рантайм не используется (против C-С1).
- Проверка при старте кода: совместимость pgvector-крейта с sqlx 0.9; фолбэк — sqlx 0.8.

## Consequences

**Положительные.** Минимальный idle-след (C-С1 — прямые деньги); родной язык владельца (bus-factor); строгая типизация в супервизоре (переподхват/идемпотентность из ADR-0001 — самое место); официальные MCP/pgvector-крейты; деплой = бинарь + Postgres в compose.

**Отрицательные (приняты).** Скорость итерации бэкенда ниже — +10–20% к паритетным оценкам ADR-0001; «быстрая» половина живёт во фронте (TS). Свежий мажор sqlx 0.9 — версионный риск первой недели.

**Нейтральные.** Донорская схема agent-dashboard переносится как схема (SQL), не как код — язык донора не имеет значения (ADR-0002).

## Alternatives considered

- **Go (chi/echo + pgx)** — быстрее итерация, но: не родной язык владельца (единственный из тройки кандидатов), в 2–4 раза дороже A по RAM при C-С1, MCP-SDK первого класса не подтверждён. Честный середняк, проигрывающий по двум персональным силам.
- **Python/Starlette (статус-кво по наследству)** — отклонён: худший по C-С1 (60–150+ МБ/воркер = деньги ежемесячно); его козырь «скорость письма» обесценен тем, что пишут агенты. Наследование стека без решения — ровно та ошибка, что чинил observe O-1.
- Отклонены без проработки: Bun/Node как прод-бэкенд (лишний рантайм против C-С1); Leptos/htmx (отказ от React против ответа владельца №3).
