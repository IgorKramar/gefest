# ADR-0009: Прослойка CLI — UUIDv7 сессий из БД, пакет граблей yao, контрактные тесты как определение

- **Date**: 2026-08-21
- **Status**: Accepted
- **Authors**: Игорь (владелец); light-цикл D-6
- Артефакты цикла: `../research/2026-08-21-prosloika-cli{,-design,-decision}.md`

## Context

Прослойка — модуль раннера между супервизором и процессом `claude` в контейнере задачи: запуск, флаги, парсер stream-json, завершение. Рамки заданы: процесс живёт всю задачу, stdin-доставка, SIGTERM-stop, контрактные тесты и пин CLI (ADR-0007); комплект `~/.claude` от брокера (ADR-0006); вехи со смещениями и сырьё файлом (ADR-0008). Донор — разбор раннера yao (docs/06 §1): 807-строчный парсер как карта граблей недокументированного stream-json-режима. Владелец: ID сессии — из БД; reasoning — только в drill-down.

## Decision

- **Идентификатор сессии:** строка sessions создаётся транзакцией **до** старта процесса; `--session-id` = её UUIDv7 (ADR-0005); после рестарта раннера — `--resume` тем же UUID; continuation-флаг выводим из состояния строки (KV-стор yao не нужен); ретрай = новая строка с `parent_session_id` (ADR-0008).
- **Пакет заимствований yao:** heredoc-запуск, системный промпт файлом (`set -e`); флаги `--input-format/--output-format stream-json --include-partial-messages --verbose`; stderr — информация, не отмена; невалидная JSONL-строка — continue; дренаж строк сверх лимита; «exit 0 без `result` + непустой stderr» = setup failed → ретрай-путь ADR-0007; **SIGKILL после финального `result`** (обход зависания stream-json-режима; дети умирают с контейнером — уборка, не потеря); `parent_tool_use_id` → дерево саб-агентов в вехах; MEMORY.md комплектом брокера не перезаписывается.
- **Не взято у yao:** игнорирование `thinking_delta` (у нас пишется в сырьё, видно в drill-down; вех на reasoning нет — поза «вехи без содержимого» ADR-0008); белый список из трёх флагов; suspend/resume групп.
- **Контракт:** S3/S4/S5 — исполняемые контрактные тесты прослойки (против фальшивого исполнителя в CI; против живого CLI — при решении об обновлении); версия CLI пинуется в образе исполнителя, обновление образа требует зелёных контрактных тестов (ADR-0007 CC-8).
- Лимит строки, heartbeat парсера — константы GF-2, меняются без пересмотра ADR.

## Consequences

**Положительные.** Одна система идентификаторов (UUIDv7 везде); грабли донора обойдены до первого наступания; смысл delivered защищён исполняемым контрактом, а не памятью о спайках.

**Отрицательные (приняты).** Зависимость от недокументированного поведения CLI остаётся — контракт её обнаруживает, но не устраняет; SIGKILL убивает детей финального процесса (в контейнере-на-задачу — приемлемо).

## Alternatives considered

- **B. UUIDv5-функция от (задача, поколение)** (путь yao) — отклонён: вторая схема ID и счётчик поколений в ключе ради «восстановления без БД» — сценария, которого у Гефеста нет (без БД раннер не работает); у yao функция компенсировала отсутствие таблицы сессий.
- **B'. Веха «мысль» на reasoning-блок** — отклонена: текст модели в БД против позы вех ADR-0008; drill-down даёт то же бесплатно.
