# ADR-0013: Документный слой — CM6/Atomic Editor с Live Preview, frontmatter-как-источник, сохранённые виды вместо DQL

- **Date**: 2026-08-21
- **Status**: Accepted
- **Authors**: Игорь (владелец); standard-цикл D-10
- Артефакты цикла: `../research/2026-08-21-dokumentnyj-sloj{,-research,-design,-decision}.md`

## Context

Документный слой заменяет Obsidian vault (C-Н5, ADR-0002). Владелец: привычки v1 — [[линки]], бэклинки, русский FTS, daily/weekly/monthly, теги, шаблоны, dataview-класс, подсветка кода, редактор с Live Preview («сырой markdown у курсора»), выборочный импорт, кнопка «в память», YAML frontmatter; история правок; канон агентам — через подтверждение. Research: reveal-у-курсора существует только в CM6-ветке (Obsidian/SilverBullet/Joplin); WYSIWYG нормализует текст round-trip-ом; готовое молодое — Atomic Editor (MIT, 06.2026); DQL не переносим (Dataview заморожен, Datacore — Obsidian-бета), сам Obsidian ушёл к GUI-видам (Bases).

## Decision

- **Редактор:** `@atomic-editor/editor` (CodeMirror 6): reveal у курсора, [[автодополнение]], подсветка; read-only режим для чтения с телефона. Предусловие интеграции — ручная проверка на телефоне и React 19 Strict Mode. **План Б встроен:** MIT-форк поверх CM6 (референсы: codemirror-live-markdown, Joplin Rich Markdown); провал проверки → своя сборка.
- **Frontmatter-как-источник:** YAML-блок в тексте — истина метаданных; при сохранении парсится в БД (теги, даты, свойства — jsonb); в редакторе — свёрнутая панель свойств, сырой YAML по клику; БД всегда производная от текста — конфликт невозможен по построению.
- **Хранение:** markdown в Postgres; история — поток событий с восстановлением версий (ADR-0005); CAS; scope_class/RLS.
- **Линки:** [[…]] → таблица `links` при сохранении, битые помечены; бэклинки и граф — запросы; FTS — хранимый tsvector `russian`.
- **Виды:** `saved_views` — JSON-спека (фильтры тег/дата/линки/свойства, сортировка, layout) → параметризованный SQL в axum; встраивание ` ```view `-блоком; computed-полей в спеке нет; люк — сохранённые raw-SQL под read-only ролью, только владельцу.
- **Агенты:** рабочие документы задачи — свободно; канон — `pending` → подтверждение владельца.
- **Периодические заметки** по шаблонам с автосозданием; **«в память»** — выделение → кандидат карточки (ADR-0003); **импорт vault** — выборочный.
- **Фазировка:** v1 — всё выше без графа и GUI-видов; итерация 2 — граф связей, конструктор видов (Bases-паттерн), raw-SQL-люк.

## Consequences

**Положительные.** Единственная ветка с нужным поведением редактора; «текст остаётся текстом» и переносимость (экспорт без потерь — frontmatter в тексте); dataview-потребность закрыта строго мощнее DQL за дни, не недели; канон без шума — четвёртое применение pending-механики.

**Отрицательные (приняты).** Bus factor апстрима ≈ 1 (пин + форк-готовность); мобильная правка — CM6-шероховатости; jsonb-свойства без схемной валидации в v1.

**Нейтральные.** Граф/GUI-виды/люк — итерация 2 forward-миграциями; провал мобильной правки → упрощённый мобильный режим (textarea+превью).

## Alternatives considered

- **B. Своя сборка на CM6** — отложена планом Б: ядро 1–2 недели, хвост (таблицы, embed, IME) — месяцы; наработки A переносимы.
- **C. Остаться на vault** — отвергнут: один источник истины не достигается, ADR-0002 нарушен.
- **WYSIWYG (Milkdown, MDXEditor)** — отвергнуты: reveal архитектурно недоступен, round-trip нормализует текст.
- **DQL-совместимость** — отвергнута: движок заморожен, standalone нет, экосистема ушла к видам.
- Не рассматривались: HyperMD/ink-mde (мертвы), Lua-runtime SilverBullet (оверкилл F7), MarkdownDB (проблема не наша).
