# ADR-0010: Периметр — два хоста со split-egress, Headscale-tailnet, passkeys; секреты в pgcrypto; пул scoped-токенов

- **Date**: 2026-08-21
- **Status**: Accepted
- **Authors**: Игорь (владелец); standard-цикл D-7
- Артефакты цикла: `../research/2026-08-21-perimetr-sekrety-broker{,-research,-design,-decision}.md`

## Context

Последнее решение серии GF-1. Владелец: Гефест — на отдельном хосте у российского провайдера; Tailscale со своим координатором (опыт есть); секреты — в БД через брокер; пул git-токенов; ресурсы — включая живые сервисы, с предложениями от агентов; egress-фильтр — дверь; алерты — Telegram+ntfy+почта. Research: api.anthropic.com с российских IP не работает (supported countries, Persona-верификация, баны 2026) — split-egress обязателен; Tailscale SaaS отдаёт 451 из РФ — Headscale 0.29.x со своим DERP; ACL пер-нодовые — контейнеры изолируются на хосте, не ACL; mTLS на iOS — Safari-only с ручной ротацией p12 → passkeys (`webauthn-rs`) выбраны вместо (roast D-4 C-4: VPN ≠ auth).

## Decision

- **Хосты:** РФ-VM — Гефест, Postgres, исполнители (рекомендация Timeweb Cloud, без публичного IPv4; провайдер — операция, не архитектура); европейский VPS — exit node + Headscale + DERP; DERP-вторичка на РФ-VM. **Split-egress:** через exit node — только домены Anthropic. Аварийный путь — SSH/консоль провайдера; алерт «tailnet недоступен».
- **Поверхности:** один axum-бинарь, два листенера: owner (панель+API) — только Tailscale-IP, вход по passkeys (enrolment — одноразовой ссылкой с авторизованного устройства); MCP — только IP контейнерного моста, авторизация scoped-токеном задачи из комплекта брокера; nftables: мост ↛ `tailscale0`; ACL tailnet — теги, deny-by-default; Tailscale identity headers не используются (подделываемы процессами хоста).
- **Секреты:** значения в Postgres под pgcrypto; ключ — файл 0600 у раннера, вне БД, копия у владельца офлайн; выдача — только комплектом брокера (ADR-0006), каждая — аудит-событие; CRUD — из панели.
- **Git-токены:** пул вручную созданных scoped-токенов (ресурсы каталога); брокер выдаёт на задачу; Гефест следит за остатком и сроками → алерт «пополни пул». Автовыдача отклонена: «токен, создающий токены» у раннера — концентрация привилегии.
- **Каталог ресурсов:** креды/env и живые сервисы (`resources`/`resource_grants`, волна 2 ADR-0005); агент предлагает → `pending` → владелец подтверждает (образец ADR-0003).
- **Egress-фильтр исполнителей:** v1 — без allowlist (изоляция контейнером); прокси-фильтр — дверь по первому инциденту (bwrap-заимствование ADR-0006).
- **Алерты:** Telegram + ntfy + почта, только факт+ссылка (C-3); отказ канала не блокирует остальные.
- **Предусловия эксплуатации:** opt-out «Improve Claude» проверен руками (C-2); риск ToS Anthropic при работе из неподдерживаемого региона — признанное ограничение владельца.

## Consequences

**Положительные.** C-4 закрыт конструкцией (биндинги+nftables), не правилом; данные — в РФ (152-ФЗ), Anthropic-egress работает; телефон — полноправный пункт управления без ротации p12; секреты не раскрываются дампом БД; привилегия создания токенов не живёт на хосте.

**Отрицательные (приняты).** Риск бана Anthropic сохраняется при любой схеме egress; падение EU VPS = пауза Anthropic-egress (снапшот+скрипт восстановления — GF-3); ключ pgcrypto на хосте — компрометация хоста раскрывает секреты (нового класса риска нет: комплекты и так инжектятся там); два хоста и две платёжки при F7; passkeys зависят от синхронизации Apple/Google.

**Нейтральные.** Пополнение пула токенов — ручная операция раз в месяцы; DERP-вторичка не требует третьего хоста.

## Alternatives considered

- **B. Три хоста** (Headscale/DERP на отдельной РФ-VM) — отклонён: падение координатора не рвёт живой tailnet (ключи узлов у клиентов; страдают приём новых нод и смена ACL — редкие операции), третья VM не окупается при одном операторе.
- **C. Статус-кво** (хост AFFiNE) — снят вводной владельца; исполнители с российского IP не работают.
- **mTLS** вместо passkeys — отклонён по research (Safari-only на iOS, ручная ротация p12 на каждом устройстве, peer-серты в axum — через обёртки).
- Не рассматривались: внешний Vault-класс (C-С1/F7), автовыдача токенов через API хостинга (концентрация привилегии), identity headers как auth (подделываемы), официальный Tailscale SaaS (451 из РФ).
