# ADR-0008: Сессии и журнал — вехи-указатели в сырьё, единая машина состояний, саммари на границах жизни

- **Date**: 2026-08-21
- **Status**: Accepted
- **Authors**: Игорь (владелец); light-цикл D-5
- Артефакты цикла: `../research/2026-08-21-sessii-zhurnal{,-design,-decision}.md`

## Context

Носители уже решены: вехи в БД (90 дней), сырой stream-json файлами 0700 вне бэкапа (janitor 30 дней), scope_class на sessions/session_events (ADR-0005); синтетическое закрытие, вопрос-как-событие, белые списки limit-полей (ADR-0007). Осталось: машина состояний сессии одним перечислением, инвариант «видимое = залогировано», таксономия вех, контракт саммари, родословная сессий и как владелец «проваливается в диалог» из панели. Владелец: вехи с drill-down в диалог (live-хвост не нужен); вехи на каждый tool-вызов; саммари при завершении/усыплении.

## Decision

- **Машина состояний:** `spawning` → `running` ⇄ `waiting_answer` (+ за флагом: `stopping` → `sleeping_cold`) → `completed` | `interrupted` | `failed`; переводит только раннер, каждый переход — событие session_events; осиротевшие при старте бинаря → `interrupted` (reconciliation ADR-0005).
- **Вехи:** границы ходов — с указателями `(raw_file, byte_from, byte_to)`; tool-вызовы (имя, длительность, статус — без аргументов); вопрос агента; interrupted; limit-события белым списком; `raw_state`/ENOSPC. События доставки — только в `command_deliveries` (ADR-0007).
- **Drill-down:** «показать диалог» = API-срез raw-файла по смещениям вехи (читает раннер, авторизация — RLS-контекст задачи); после 30 дней — «сырьё истекло», остаются вехи и саммари. Live-хвоста нет: статусы и лента панели — только из БД («видимое = залогировано»).
- **Саммари:** исполнитель — при завершении и уходе в `waiting_answer`; умер без саммари → веха `summary_missing`, панель показывает предыдущее с пометкой; ретрай не блокируется.
- **Родословная:** сессия ретрая/рестарта несёт `parent_session_id`; живая на задачу — одна; панель показывает цепочку.

## Consequences

**Положительные.** Один носитель клиентского текста (raw; команды и вопросы — в БД по построению) — одна политика retention и «удалить с производными»; поза «сырьё вне БД» (C-С1) цела; «чем занят агент» видно из журнала 90 дней без чтения сырья.

**Отрицательные (приняты).** Диалог старше 30 дней невосстановим (саммари/вехи остаются; лечится настройкой janitor); битый raw → срез недоступен, fallback — саммари; writer обязан писать смещения синхронно с вехой (GF-2).

## Alternatives considered

- **B. Диалог-события в БД** (тексты сообщений в session_events, drill-down 90 дней) — отклонён: второй носитель клиентского текста со своей политикой удаления и бэкапом, БД растёт с болтливостью модели — поверхность, которую ADR-0005 закрывал.
- Не рассматривались: live-хвост сырья в панель (снят владельцем), полный ES (отвергнут ADR-0005), гибрид «часть текста в вехах» (обе политики сразу).
