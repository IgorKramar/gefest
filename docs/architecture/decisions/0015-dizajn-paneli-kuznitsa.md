# ADR-0015: Дизайн панели — «тёмная кузница», сайдбар-IA, Base UI под своей айдентикой, PWA с очередью решений

- **Date**: 2026-08-21
- **Status**: Accepted
- **Authors**: Игорь (владелец); standard-цикл D-18
- Артефакты цикла: `../research/2026-08-21-dizajn-paneli{,-research,-design,-decision}.md`; **нормативные ТЗ**: `../../design/tz-web-panel.md`, `../../design/tz-mobile-pwa.md`

## Context

Функциональный состав панели решён серией ADR (статусы 0007/0008, чат 0011, pending-потоки 0003/0010/0011/0013, ресурсы 0010); не был решён облик. Владелец: характер — гибрид с выраженной «тёмной кузницей»; обе темы; многостраничность с доской задач во главе; переключаемая плотность; вся видимая айдентика своя (скорректировано с «полностью своей» до «своя поверх headless» по возражению архитектора); полный набор живости агента; топ-3 мобильных действий — по совету архитектора. Research: Base UI 1.x — рекомендуемый headless (экс-Radix в MUI, полный состав, shadcn/ui переехал на неё по умолчанию); web push iOS работает для установленной PWA, но best-effort; passkeys в standalone same-origin работают; шрифты — Tektur/Golos Text/JetBrains Mono (variable, родная кириллица, OFL).

## Decision

- **Характер:** «тёмная кузница» — сдержанная тёпло-графитовая база, огненная янтарная шкала oklch, зарезервированная за активностью («огонь = работа»); светлая тема «остывший металл»; обе + системное авто. Эпичность — в деталях (SVG-иконография с доменными глифами, пустые состояния, именование), не в декоре.
- **Типографика:** Tektur (заголовки) + Golos Text (UI-текст) + JetBrains Mono (данные/терминальные акценты); self-hosted.
- **Компоненты:** поведение — Base UI; вся видимая айдентика своя (токены + доменные компоненты: карточка агента, трасса доставки, лента вех, псевдотерминал, очередь решений, бейдж «почему стоит», мини-пульт). Запасной headless — React Aria Components.
- **Каркас веба:** левый сворачиваемый сайдбар; разделы: Доска задач (главная) · Агенты · Чат · Решения · Журнал · Ресурсы · Документы (Ф2, резерв) · Настройки; глобальный мини-пульт в шапке; места детекторов (D-11) зарезервированы. Плотность compact ⇄ comfortable переключателем.
- **PWA:** нижняя навигация Агенты · Решения (бейдж) · Чат · Задачи; «Решения» — единая очередь четырёх pending-потоков и вопросов агентов со свайпами; полноэкранный композер ответа; deep-link-first (восстановление после сброса процесса iOS); passkeys same-origin; свой pull-to-refresh; Журнал/Ресурсы в PWA v1 не дублируются.
- **Уведомления:** первичный канал — внешний (Telegram/ntfy/почта, ADR-0010) с deep-link; web push установленной PWA — дублирующий + Badging API.
- **Нормативные ТЗ** (`docs/design/`) — источник истины для макетов Claude Design; расхождения макетов возвращаются правкой ТЗ, не молчаливо.

## Consequences

**Положительные.** Взгляд находит работающих агентов мгновенно (огонь зарезервирован); статус всегда цвет+слово (доступность и однозначность); телефон закрывает три критических действия в одно касание; кириллица — родная во всех трёх шрифтах; ТЗ достаточно детальны для макетов без устных уточнений.

**Отрицательные (приняты).** Base UI молода (~8 мес стабильного API; semver заявлен, запасной назван); web push — best-effort и только после ручной установки PWA; Tektur без курсива; проверка variable-осей и passkeys-standalone на живом iPhone — предусловие фиксации (совместить с проверкой Atomic Editor, ADR-0013).

**Нейтральные.** Комнаты чата, Jira-класс доски, детекторы, Документы — зарезервированные места, занимаются без пересмотра; вторая плотность PWA не делается (одна, средняя).

## Alternatives considered

- **B. Верхняя навигация** — отклонена: 8 русских разделов впритык, рост упирается в «ещё», мини-пульт конкурирует за топбар.
- **C. Без дизайн-системы, экраны по месту** — отклонён: путь agent-dashboard («делалась на ходу»), против цели проекта.
- **Полностью своя компонентная система** (исходный Q6-б) — скорректирована владельцем после возражения: поведенческие примитивы с нуля — месяцы работы над фокусом/клавиатурой/доступностью без вклада в характер.
- **Готовая стилизованная библиотека (shadcn/ui-класс как есть)** — отклонена владельцем (Q6): недостаточно своя.
- **Web push как первичный канал алертов** — отклонён research-ом: best-effort, зависит от установки и состояния PWA; первичный канал обязан быть server-side.
