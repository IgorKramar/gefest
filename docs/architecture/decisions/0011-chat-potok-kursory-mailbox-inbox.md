# ADR-0011: Взаимодействие агентов — чат-поток с курсорами, mailbox через единый инбокс, права по проекту

- **Date**: 2026-08-21
- **Status**: Accepted
- **Authors**: Игорь (владелец); standard-цикл D-9
- Артефакты цикла: `../research/2026-08-21-vzaimodejstvie-agentov{,-design,-decision}.md`

## Context

Агенты изолированы контейнерами (ADR-0006) и общаются только через Гефест; механика доставки решена (ADR-0007: единый инбокс, `command` ≠ `message`, message ждёт `queued` без пробуждения). Владелец: один общий чат + адресные mailbox; адресное — push, чат — pull; «прочитано» отдельно от «доставлено» (F-3); права — в рамках общего проекта; эскалация непрочитанного; сабагентам — автопередача, чужим — с подтверждением; сообщения владельца в чате приоритетны для ролей. Research пропущен: семантика строится на собственной инфраструктуре, version-sensitive утверждений нет.

## Decision

- **Чат:** `chat_messages (channel_id, version)` — append-only поток по конституции ADR-0005; один канал в v1, комнаты — дверь (`channel_id`); чтение — pull MCP-инструментом на границах хода; `read` = курсор читателя (паттерн consumer_offsets); история доступна новым участникам; сообщения владельца помечены и отдаются с приоритетной маркировкой (инструкция ролей — разбирать первыми).
- **Mailbox:** адресный `message` — единый инбокс ADR-0007 (push в stdin, каузальный delivered); `read` — при чтении инбокса; панель различает «доставлено» и «прочитано».
- **Права:** писать (адресно и в чат) — в рамках общего проекта; broadcast-указания — только владелец; владелец видит всё.
- **Эскалация:** message без прочтения дольше порога (настройка, старт 24 ч) → алерт факт+ссылка с действиями «запустить роль / переадресовать / снять».
- **Передача работы:** своему сабагенту — автоматически (механика Claude Code внутри контейнера задачи); другому агенту — `pending` → подтверждение владельца; автопередача доверенным парам — дверь D-16.
- **Гарантии:** чат не обещает своевременности — для немедленного и гарантированного рядом в панели «отправить как указание» (машина ADR-0007).
- **Приватность:** таблицы чата/mailbox — scope_class, retention тела 90 дней, «удалить с производными» включает; алерты — факт+ссылка (политика ADR-0007 п.8).

## Consequences

**Положительные.** Координация без владельца-посредника; ноль токенов на поллинг и пробуждения (pull на границах, `queued` спящим); третье применение готового паттерна потока — нет нового механизма; история канала — общая память координации; след и права — по построению.

**Отрицательные (приняты).** Чат-«стоп» может опоздать на длину хода (лечится указанием); read-курсор не различает «понял» и «пролистал»; порог эскалации один на всех в v1.

**Нейтральные.** Комнаты, per-роль пороги, автопередача парам — двери forward-миграцией; всё в волне 2 схемы.

## Alternatives considered

- **B. Fan-out через инбокс** (чат-сообщение = N адресных message) — отклонён: ×N записей, состав «всех» фиксируется при отправке — новые агенты без истории; read через deliveries вместо естественного курсора.
- **C. Статус-кво** (координация через владельца) — отклонён: владелец — узкое место, боль цикла.
- Не рассматривались: внешний мессенджер/шина (антипаттерн «общий канал — только через Гефест», ADR-0006); push чата всем в stdin (шум в контексте, отклонено владельцем); отдельный чат-сервис (F7, C-С1).
