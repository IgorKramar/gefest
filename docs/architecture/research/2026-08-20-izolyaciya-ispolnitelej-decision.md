# Decision summary: модель изоляции исполнителей (D-3, standard)

- Дата: 2026-08-20 · Статус: **принято владельцем** («Согласен», после разбора механики брокера; 2026-08-20)

**Выбрано — A: rootless-контейнер на задачу** (bollard; podman rootless предпочтителен, docker rootless допустим — выбор рантайма при GF-2), с конструкциями:

1. **Per-task эфемерно (C-И1):** контейнер создаётся раннером под задачу, умирает по завершении; контекст — из канона (память роли генерируется в песочницу, сессия резюмится, кандидаты копируются при предложении); housekeeping — labels (`gefest.task_id`, `created_at`) + reaper + TTL-sweep (Ryuk-паттерн); реестр восстановим из labels после crash.
2. **Комплект брокера (C-И4/И5):** prepare-шаг (идемпотентный, маркер-хэш) собирает: worktree, чистую dev-БД (`CREATE DATABASE ... TEMPLATE`, ~10–40 мс, сериализованно, к шаблону никто не коннектится; `DROP ... WITH (FORCE)` при уборке), env выданных ресурсов из каталога (`resources`/`resource_grants` — волна 2 схемы), scoped git-токен, `~/.claude`-набор (креды ro + память роли + hooks). Секреты живут только у раннера, инжектятся и умирают с песочницей. Docker исполнителю не выдаётся.
3. **Изоляция (C-И2):** namespaces ФС/сеть/pid; том задачи — единственная видимая ФС; общий канал агентов — только через Гефест (чат — D-9). Лимиты CPU/RAM — с v1 (C-И3; предпроверка cgroups v2 systemd-делегирования cpu/cpuset на хосте — в GF-2).
4. **Сеть:** egress к Anthropic/git-хостингам/MCP Гефеста; доменная прокси-фильтрация — добавляется в D-7 (заимствование из пути вендоров).
5. **П-И1 (подтверждено):** триггер кубера уточнён — второй хост или устойчивая нехватка ресурсов; контейнер-на-задачу переносится в под дословно, каталог ресурсов = будущий provisioning.

**Почему:** «жёстко» + лимиты + housekeeping + путь в поды — четыре силы за A против двух за B (скорость старта, доменный прокси — оба заимствуются позже); эфемерные БД решены шаблонами без контейнеров; DinD снят («чистая база» от Гефеста).

**Отдаём:** свой образ исполнителя (Node+CLI; обновление вслед релизам CLI — конвейер), прогрев cold-start (`--userns` кэш), сокет рантайма у раннера (rootless смягчает; ограждение — D-7).

**Границы пересмотра:** cold-start мешает UX → bwrap-режим для лёгких задач (дверь открыта); второй хост → поды (П-И1); прокси-фильтрация — D-7.

**Roast:** пропущен по масштабу standard (сила-конфликтов на уровне deep нет; решение обратимо — песочница не хранит состояния). Ревью реализации — `/architect:review` после GF-2.
