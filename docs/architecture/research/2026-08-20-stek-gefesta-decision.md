# Decision summary: стек Гефеста (D-1, light)

- Дата: 2026-08-20 · Статус: **принято владельцем** («Подтверждаю A», после lean «как насчёт rust?» и двух раундов discovery)

**Выбрано — A:** бэкенд **Rust** (axum 0.8 + tokio + sqlx + rmcp + pgvector-crate), один бинарь, статика фронта внутри; фронтенд **React 19 + TypeScript + Vite 8 + TanStack Router/Query + Tailwind CSS 4**; **Bun — toolchain** (install/test/dev-скрипты), не прод-рантайм; SSE — нативный EventSource + инвалидация Query.

**Почему:** C-С1 (биллинг по ресурсам → idle-RAM = деньги: Rust ~5–30 МБ < Go ×2–4 < Python 60–150+); Rust — родной язык владельца (bus-factor); MCP/pgvector — официальные зрелые крейты (research); код пишут агенты — Rust им не помеха; один бинарь = минимальная эксплуатация (F7).

**Отдаём:** скорость итерации бэкенда (+10–20% к срокам — принято); свежесть sqlx 0.9 (проверка совместимости pgvector при первом `cargo add`, фолбэк 0.8).

**Границы пересмотра:** Bun-бандлер догоняет Vite для React-SPA → пересмотр сборки; появляется нужда в быстром серверном прототипировании, которую TS-фронт не покрывает → точечные вспомогательные скрипты на Python допустимы (не сервисы).

**Roast:** пропущен по масштабу light (blast radius — ноль строк существующего кода; альтернатив две; силы отвечены владельцем напрямую).
