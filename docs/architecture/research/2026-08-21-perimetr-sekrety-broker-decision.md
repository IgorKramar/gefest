# Decision summary: периметр, секреты и брокер ресурсов (D-7)

- Дата: 2026-08-21 · Фаза: Decide (standard) · Входы: discovery (Q1–Q8 + вводная про отдельный хост), research digest (2 потока), design (A/B/C)
- Статус: **принято владельцем** («A», 2026-08-21).

## Выбранное

**A: два хоста** + общая часть design:

1. **Хосты:** РФ-VM (Гефест + Postgres + исполнители; рекомендация — Timeweb Cloud, фикс ~1200–1700 ₽/мес, без публичного IPv4, S3 для pg_dump; смена провайдера — операция) + европейский VPS (exit node + Headscale 0.29.x + DERP; ~€3–5/мес). DERP-вторичка на РФ-VM (embedded, несколько релеев) — смягчение глушения WireGuard внутри РФ. Аварийный путь — SSH/консоль провайдера; алерт «tailnet недоступен».
2. **Split-egress (Q8):** через exit node — только домены Anthropic; остальной трафик — напрямую. Риск ToS Anthropic (неподдерживаемый регион) признан владельцем и записан ограничением; opt-out «Improve Claude» — предусловие эксплуатации (C-2).
3. **Auth владельца (Q2, пересмотрен по research):** passkeys/WebAuthn (`webauthn-rs`) на owner-листенере; enrolment нового устройства — одноразовой ссылкой с авторизованного; mTLS отклонён (Safari-only на iOS, ручная ротация p12). VPN ≠ auth (C-4 закрыт).
4. **Разделение поверхностей:** owner-листенер — только Tailscale-IP; MCP-листенер — только IP контейнерного моста, авторизация scoped-токеном задачи из комплекта брокера; nftables мост↛`tailscale0`; ACL tailnet — теги, deny-by-default; identity headers не используются (подделываемы из контейнеров).
5. **Секреты (Q3-б):** Postgres + pgcrypto; ключ шифрования — файл 0600 у раннера, вне БД (копия у владельца офлайн); pg_dump без ключа секреты не раскрывает; выдача — только комплектом брокера, каждая выдача — аудит-событие; CRUD — из панели.
6. **Git-токены (Q4):** пул вручную созданных scoped-токенов как ресурсы; брокер выдаёт на задачу; Гефест следит за остатком/истечением → алерт «пополни пул». Автовыдачи нет — у раннера не живёт «токен, создающий токены».
7. **Каталог (Q5):** ресурсы = креды/env и живые сервисы; агент предлагает → `pending` → владелец подтверждает (образец ADR-0003); `resources`/`resource_grants` — волна 2 ADR-0005.
8. **Egress-фильтр (Q6):** v1 без доменного allowlist (изоляция контейнером); прокси-фильтр — дверь по первому инциденту.
9. **Алерты (Q7):** Telegram + ntfy + почта; только факт+ссылка (C-3); отказ канала не блокирует остальные.

## Почему

Исполнители с российского IP не работают (research: supported countries, Persona, баны 2026) — split-egress обязателен, и один европейский VPS закрывает сразу три роли (exit node, координатор, DERP); падение координатора не рвёт живой tailnet (ключи узлов у клиентов) — изоляция control plane третьим хостом не окупается при F7. Passkeys против mTLS — телефон как полноправный пункт управления против «Safari-only + ежегодный p12». Пул токенов против автовыдачи — концентрация привилегии у раннера хуже ручного пополнения раз в месяцы.

## Что отдаём

Риск бана Anthropic при egress из неподдерживаемого региона — остаётся при любой схеме, принят; падение EU VPS = потеря Anthropic-egress до восстановления (снапшот VPS + скрипт восстановления — GF-3); passkeys зависят от синхронизации Apple/Google-аккаунтов владельца; ключ pgcrypto на хосте — компрометация хоста раскрывает секреты (смягчение: секреты и так инжектятся задачам на этом хосте — новый класс риска не создаётся); третий хост (изоляция control plane) отвергнут осознанно.

## Операционные последствия

Новая задача GF-6 (инфраструктура периметра): два хоста, headscale+DERP+exit node, ACL, nftables, passkeys-регистрация, ключ pgcrypto, каналы алертов, пул токенов. GF-2: MCP-листенер на мосту, scoped-токены комплекта. GF-5: таблицы secrets/выдач — волна 2 forward-миграцией. Бэкап pg_dump — в S3 РФ-провайдера, шифрование ключом вне БД.

## Границы пересмотра

Глушение WireGuard ломает связность при DERP-вторичке → третий хост/AmneziaWG-класс решением; первый egress-инцидент исполнителя → allowlist-прокси (дверь Q6); второй оператор → ревизия enrolment и ролей passkeys; Anthropic открывает регион/меняет политику → упрощение egress; пул токенов пустеет чаще раза в месяц → пересмотр автовыдачи.
