# Discovery: дизайн веб-панели и мобильного PWA (D-18)

- Дата: 2026-08-21 · Масштаб: standard · Вход: запрос владельца («требования к дизайну + два ТЗ для Claude Design»)
- Выход цикла (расширен владельцем): decision + ADR + **два ТЗ** (`docs/design/tz-web-panel.md`, `docs/design/tz-mobile-pwa.md`) для Claude Design.

## Problem

Панель — единственный интерфейс владельца к Гефесту. Функциональный состав уже решён серией ADR; не решено, **как это выглядит и ощущается**: информационная архитектура экранов, визуальный характер, плотность, мобильная раскладка, паттерны реального времени. ТЗ должны быть достаточно подробными, чтобы Claude Design выдал макеты без устных уточнений.

## Forces (что панель обязана показывать/уметь — из принятых ADR)

- **Живые статусы агентов** (боль №1 консолидации): состояние сессий (машина ADR-0008), «чем занят» из вех (tool-вызовы), «почему стоит» (`quota`/`limit`/`probe`/`sleeping`, ADR-0007).
- **Трасса доставки указаний**: queued→sent→delivered, cancelled_by_stop, «доставлено ≠ прочитано» (ADR-0007/0011); кнопка «отправить как указание» рядом с чатом.
- **Доска задач** (Atlassian-ключи; Jira-класс — Ф2-дверь D-15); **чат агентов** с приоритетной маркировкой сообщений владельца; **вопросы агентов** с ответом из панели; **подтверждения pending** (память ADR-0003, ресурсы ADR-0010, канон документов и передача работы ADR-0011/0013) — четыре потока одного жанра «предложение → да/нет».
- **Drill-down в диалог** — срез сырья по вехе (ADR-0008); **документы** с CM6-редактором Live Preview — Ф2 (ADR-0013), но IA-место резервируется сейчас.
- **Каталог ресурсов и секретов** (CRUD владельца, выдачи с аудитом); **детекторы расхождений** (Ф1, D-11 — место резервируется); **родословная сессий** (parent_session_id).
- Вход — passkeys поверх tailnet; телефон — полноправный пункт управления (чтение чаще, правка возможна — ответ D-10 Q4); фронт — React 19 + Tailwind 4 (ADR-0004).
- Один пользователь v1 (второй оператор — дверь); русский язык интерфейса; кириллическая типографика.

## Open questions (владельцу)

- **Q1. Визуальный характер.** Гефест — кузнец с автоматонами: (а) выразительная айдентика — тёмная «кузница» (глубокие тёмные тона, огненные акценты, характерные заголовки), эпичность в деталях; (б) нейтральный рабочий инструмент (спокойный минимализм, ничего лишнего); (в) гибрид — сдержанная база + фирменные акценты (иконография, пустые состояния, имена). Что ближе твоему вкусу на каждый день?
- **Q2. Темы.** Только тёмная / только светлая / обе с переключателем и системным авто? (Влияет на объём ТЗ — токены обеих тем.)
- **Q3. Главный экран веба.** Что видишь первым: (а) «пульт» — сводка всех агентов сейчас (кто работает/спит/ждёт, алерты, pending-очередь); (б) доска задач, агенты — сбоку; (в) лента событий (журнал)? 
- **Q4. Мобильные сценарии-приоритеты.** Что обязано быть «в одно касание» с телефона: подтверждения pending? ответы на вопросы агентов? стоп агента? быстрая команда? Назови топ-3 — они определят нижнюю навигацию PWA.
- **Q5. Плотность веба.** (а) Плотный таблично-терминальный стиль (много данных на экран, моноширинные акценты — «пульт оператора»); (б) просторный карточный (воздух, крупные статусы); (в) плотность переключаемая?
- **Q6. Компонентная база.** (а) shadcn/ui-класс поверх Tailwind 4 (готовые примитивы, свой стиль токенами — быстро и консистентно); (б) полностью своя система (дороже, уникальнее). Для ТЗ это раздел «компоненты: кастомизировать vs рисовать с нуля».
- **Q7. Живость агента.** Как показывать «агент работает прямо сейчас»: (а) статус + последняя веха текстом («Bash: cargo test, 40 с»); (б) + мини-лента вех в карточке агента (последние 3–5); (в) + псевдотерминальная строка прогресса? (Live-хвоста сырья нет — ADR-0008; всё из вех.)

## Ответы владельца (2026-08-21)

- Q1: (в), ближе к (а) — гибрид с выраженным характером «тёмной кузницы»: сдержанная база + огненно-тёмные акценты, эпичность в деталях (иконография, пустые состояния, имена).
- Q2: обе темы с переключателем (+системное авто).
- Q3: (б) — доска задач как главная; панель **многостраничная** (разделы, не одна перегруженная страница).
- Q4: по совету архитектора — топ-3 «в одно касание»: ответить агенту; разобрать очередь «Решения» (единая очередь четырёх pending-потоков со свайпами); стоп/быстрое указание с карточки агента. Нижняя навигация PWA: Агенты · Решения (бейдж) · Чат · Задачи.
- Q5: (в) — переключаемая плотность (плотный «пульт оператора» ⇄ просторный карточный).
- Q6: (б), скорректировано по возражению архитектора и принято владельцем: **вся видимая айдентика своя** (токены, типографика, доменные компоненты), поведенческие примитивы — headless-библиотека (выбор — по research).
- Q7: всё перечисленное — статус + последняя веха, мини-лента вех в карточке, псевдотерминальная строка прогресса.

## Success criteria

Два ТЗ, по которым Claude Design выдаёт макеты без уточняющих вопросов: карта экранов, состав и состояния каждого экрана, компоненты, токены (цвет/типографика/отступы), пустые/ошибочные/загрузочные состояния, мобильная навигация; ADR фиксирует дизайн-принципы, не привязывая к конкретным макетам.
