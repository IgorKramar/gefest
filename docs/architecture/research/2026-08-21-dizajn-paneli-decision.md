# Decision summary: дизайн веб-панели и мобильного PWA (D-18)

- Дата: 2026-08-21 · Фаза: Decide (standard) · Входы: discovery (Q1–Q7), research (3 темы), design (A/B/C + состав ТЗ)
- Статус: **принято владельцем** («А», 2026-08-21).

## Выбранное

**A: левый сайдбар** + общая часть design:

1. **Характер:** «тёмная кузница», гибрид с выраженным характером: тёмная тёпло-графитовая база + огненная янтарная акцентная шкала (oklch, единые хрома/светлота по семейству статусов); светлая тема «остывший металл»; обе темы + системное авто. Эпичность — в деталях: иконография (инлайн-SVG, stroke, сетка 16/20/24), пустые состояния, именование; база сдержанна.
2. **Типографика:** Tektur (заголовки) + Golos Text (текст/данные) + JetBrains Mono (терминальные акценты); все variable, self-hosted (CSP без внешних хостов).
3. **Компоненты:** поведение — Base UI; вся видимая айдентика своя (токены + доменные компоненты).
4. **Плотность:** переключатель compact ⇄ comfortable (два набора токенов отступов/кеглей).
5. **IA веба:** многостраничная, сайдбар (сворачиваемый до иконок): Доска задач (главная) · Агенты · Чат · Решения · Журнал · Ресурсы · Документы (Ф2, резерв) · Настройки; глобальный мини-пульт агентов в шапке; детекторы (D-11) — виджет Доски + фильтр Журнала (резерв).
6. **Живость:** статус машины ADR-0008 + последняя веха + мини-лента 3–5 вех + псевдотерминальная строка (всё из вех; live-хвоста нет — ADR-0008); «почему стоит» — бейдж первого класса.
7. **PWA:** нижняя навигация Агенты · Решения (бейдж) · Чат · Задачи; «Решения» — единая очередь четырёх pending-потоков + вопросов, свайпы; passkeys same-origin в standalone; алерты первично Telegram/ntfy, web push установленной PWA — дублирующий + Badging; свой pull-to-refresh; восстановление по deep-link после сброса процесса iOS.
8. **Выход цикла:** ADR-0015 (принципы) + два ТЗ в `docs/design/` по составу design-документа (10 разделов, включая анти-слоп) — норматив для макетов Claude Design.

## Почему

Все содержательные силы заданы принятыми ADR (панель показывает то, что решено в 0007/0008/0010/0011/0013); вкусовые оси закрыты владельцем (Q1–Q7), технологические — research с датами (Base UI, PWA-реальность iOS, кириллические шрифты); сайдбар — единственная навигация, масштабируемая на 8+ русских разделов с ростом.

## Что отдаём

Base UI молода (~8 мес стабильности; semver заявлен); web push на iOS — best-effort и только после ручной установки (принято: первичный канал внешний); Tektur без курсива (курсив — Golos); проверка variable-осей и passkeys-standalone на живом iPhone — предусловие фиксации (совместить с проверкой Atomic Editor, ADR-0013); ТЗ — норматив, макеты Claude Design могут его уточнить (расхождения возвращаются в ТЗ правкой, не молчаливо).

## Операционные последствия

`docs/design/tz-web-panel.md`, `docs/design/tz-mobile-pwa.md` — владелец закидывает в Claude Design; GF-задача на реализацию фронта — после макетов (панель строится по ходу GF-2+); шрифты self-hosted — в `web/` при старте фронта.

## Границы пересмотра

Макеты Claude Design ломают IA → правка ТЗ и, при смене каркаса, пересмотр A; Base UI спотыкается на React 19/Tailwind 4 в первом спайке фронта → React Aria Components (запасной назван research); второй оператор → ревизия «Решений» (чьи подтверждения) и настроек; детекторы/документы при активации занимают зарезервированные места без пересмотра.
