# Design: периметр, секреты и брокер ресурсов (D-7)

- Дата: 2026-08-21 · Масштаб: standard · Входы: discovery + ответы владельца (Q1–Q8), research digest

## Общая часть (инвариантна к альтернативам)

- **Tailnet:** Headscale 0.29.x со своим DERP; официальные клиенты с custom server URL; устройства владельца и хост Гефеста — теги, deny-by-default; на Tailscale SaaS не закладываемся (451 из РФ). Exit node в Европе; policy-routing: через exit node — только домены Anthropic (split-egress), остальной трафик хоста — напрямую.
- **Разделение поверхностей (закрывает C-4):** два листенера одного axum-бинаря: owner-API + панель — только на Tailscale-IP хоста, вход по passkeys (`webauthn-rs`; enrolment нового устройства — по одноразовой ссылке, выданной с уже авторизованного); MCP-listener для исполнителей — только на IP контейнерного моста (без TLS, авторизация scoped-токеном задачи из комплекта брокера); nftables: мост → `tailscale0` запрещён; контейнеры не в host netns (ADR-0006). ACL tailnet контейнеров не видит — изоляция хостовая, конструкцией.
- **Аварийный путь:** SSH к VM по ключу через публичный IP провайдера (или консоль провайдера, если IPv4 не берём) — на случай падения tailnet; алерт «tailnet недоступен» по heartbeat.
- **Секреты (Q3-б):** значения — в Postgres под pgcrypto; **ключ шифрования — файлом 0600 у раннера, вне БД** (pg_dump без ключа секреты не раскрывает; копия ключа — у владельца офлайн); выдача — только через комплект брокера (ADR-0006), каждая выдача — событие аудита (кто/что/какой задаче/когда); owner-CRUD секретов — из панели.
- **Git-токены (Q4):** пул заранее созданных вручную scoped-токенов (fine-grained PAT / project tokens) как ресурсы каталога; брокер выдаёт из пула на задачу; Гефест следит за остатком и истечением — алерт «пополни пул» (факт+ссылка). Автовыдачи через API хостинга нет — у раннера не появляется «токен, создающий токены».
- **Каталог ресурсов (Q5):** `resources`/`resource_grants` (волна 2 ADR-0005); типы — креды/env И живые сервисы (dev-БД, тестовые аккаунты); агент предлагает ресурс → `pending` → владелец подтверждает в панели (образец — кандидаты памяти ADR-0003); выдача/отзыв — след автор/адресат.
- **Egress-фильтр (Q6):** v1 — без доменного фильтра (изоляция контейнером, ADR-0006); allowlist-прокси — дверь по первому инциденту (заимствование bwrap-пути, ADR-0006).
- **Алерты (Q7):** три канала — Telegram-бот, ntfy-push, почта; содержимое — только факт+ссылка (C-3); каналы — настройка, отказ канала не блокирует остальные.
- **Предусловие эксплуатации:** opt-out «Improve Claude» проверен руками (C-2); риск ToS Anthropic при egress из неподдерживаемого региона — признан владельцем, зафиксирован как ограничение.

## Альтернативы (раскладка хостов)

**A. Два хоста: РФ-VM (Гефест+Postgres+исполнители) + один европейский VPS (exit node + Headscale + DERP).** Вся инфраструктура периметра — на одной зарубежной точке; РФ-VM держит данные (152-ФЗ) и рабочую нагрузку.

**B. Три хоста: A + Headscale/DERP на отдельной маленькой РФ-VM.** Control plane tailnet переживает компрометацию/недоступность и Гефеста, и exit node; DERP внутри РФ устойчивее к глушению WireGuard на межграничных линках.

**C. Статус-кво (хост AFFiNE, без отдельного хоста)** — снят вводной владельца; в матрице для полноты.

| Критерий | A: два хоста | B: три хоста | C: статус-кво |
|---|---|---|---|
| Штук хостов/платёжек | 2 | 3 | 1 |
| Цена порядка | ~1500 ₽ (РФ) + ~€3–5 (EU) | + ещё ~300–500 ₽ | 0 |
| Падение exit node | Теряем Anthropic-egress И координатор (новые ноды не входят; **существующие связи живут** — ключи узлов на устройствах) | Теряем только egress | — |
| DERP при глушении WG на границе | DERP за границей — связность владелец(РФ)↔хост(РФ) через европейский релей, хуже | DERP в РФ — лучше | — |
| Компрометация Гефест-хоста | Control plane цел (он на EU VPS) | Control plane цел | Всё едино |
| F7 (один оператор) | Два хоста обслуживать | Три хоста | Один |
| Anthropic-исполнители | Работают (egress EU) | Работают | **Не работают** (RF IP) |

**Lean автора — A**: недоступность координатора не рвёт существующий tailnet (ключи узлов у клиентов, меш живёт; страдает только приём новых нод и смена ACL — не ежедневные операции), поэтому изоляция control plane на третий хост не окупает третью VM и третью платёжку при F7. Слабое место A — DERP за границей: если РКН глушит WireGuard и внутри РФ, связь «владелец в РФ ↔ хост в РФ» пойдёт через европейский релей; смягчение — DERP-вторичка на самой РФ-VM Гефеста (headscale embedded DERP умеет несколько релеев) без третьего хоста.
**Провайдер РФ-VM:** нагрузка резидентна 24/7 (раннер ждёт команд) — преимущество Yandex «останов = не платим» не реализуется; рекомендация — **Timeweb Cloud** (фикс ~1200–1700 ₽/мес, S3 рядом для pg_dump, можно без публичного IPv4 — вход только tailnet + консоль провайдера как аварийный путь). Yandex Cloud — если захочется их S3/снапшот-экосистему; смена провайдера — операция, не архитектура.
