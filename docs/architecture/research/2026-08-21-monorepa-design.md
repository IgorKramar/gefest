# Design: организация монорепы (D-17)

- Дата: 2026-08-21 · Масштаб: deep · Входы: discovery (2 раунда, Q1–Q8), research digest

## Общая часть (из ответов и research, инвариантна к альтернативам)

Корневой `Cargo.toml`: workspace, `edition = "2024"`, `workspace.dependencies` (с `default-features = false` там, где нужна гибкость фич — ловушка edition 2024), `workspace.lints`. `.sqlx` — в корне, `cargo sqlx prepare --workspace`; CI: обычные job-ы с `SQLX_OFFLINE=true` (флаг в CI-env, не в `.env` — грабли #3836), отдельный job с Postgres: `migrate run` + `prepare --check --workspace`; sqlx-cli пинован `--locked`. Статика: `bun run build` → `web/dist` → embed крейтом `api` (**static-serve**; правила: hashed — `immutable`, `index.html` — `no-cache`; пустой `dist` валит сборку громко). `hef` — тонкий бинарь (main + clap). Docker: `infra/Dockerfile` (bun-стадия → cargo-chef → slim), контекст от корня, `.dockerignore` (`target/`, `web/node_modules`, `web/dist`). Раннер задач — **mise tasks** (Q8: параллельный dev `vite + bacon`, наследование тулчейна, тот же раннер в CI); bacon вместо мёртвого cargo-watch. Образ исполнителя — `infra/executor-image/` (пин CLI + контрактные тесты меняются одним PR). Контрактные тесты — `tests/contract/`. `docs/` — не трогается.

## Альтернативы (форма workspace)

**A. Доменная шестёрка (базовая, из Q1-а + research):**

```
crates/
  core/           # типы, перечисления-истина, ошибки; БЕЗ tokio/axum
  db/             # прослойка доступа ADR-0005, migrations/, все query-макросы
  runner/         # супервизор + прослойка CLI (ADR-0009) + брокер комплектов
  api/            # axum: owner-listener + MCP-listener (rmcp) + embed статики
  hef/            # тонкий бинарь: clap-подкоманды serve/migrate/...
  fake-executor/  # тестовый бинарь-симулятор stream-json
web/  infra/  tests/contract/  docs/
```

Инварианты графа: `core` ни от кого; `db`→`core`; `runner`→`db,core`; `api`→`runner,db,core`; `hef`→`api`; `fake-executor`→`core`. Анти-паттерн «крейт-звезда» сдерживается правилом: в `core` — только типы без поведения и рантайма.

**B. Компактная тройка:** `gefest` (api+runner+db модулями одного крейта), `core`, `fake-executor`. Быстрее старт, меньше Cargo.toml-ов; границы — дисциплиной модулей, инкрементальная сборка хуже (любая правка пересобирает весь крейт), агенту-коммиттеру границы видны слабее.

**C. Мелкозернистая (8+):** A + отдельные `mcp`, `cli-layer` (прослойка отдельно от раннера), `migrations`. Жёстче границы, но research: rmcp на этом объёме — внутри `api`; риск лишних пересборок каскадом и «нарезки на модуль», навигация хуже.

**D. Статус-кво-стиль `backend/` + `frontend/`:** один Rust-крейт в `backend/` без workspace (rustzen-паттерн). Минимум структуры; не даёт ни границ, ни инкрементальности, ни path-фильтров по доменам; переезд в workspace потом — переименование всего.

| Критерий | A: шестёрка | B: тройка | C: 8+ | D: backend/frontend |
|---|---|---|---|---|
| Границы для агентов | По каталогу очевидны | Дисциплина модулей | Очевидны, но дробно | Нет |
| Инкрементальная сборка | Хорошая (core стабилен) | Хуже (монолит-крейт) | Хорошая, но каскады прок-макросов | Хуже |
| Path-фильтры CI | Чистые | Грубые | Чистые | Грубые |
| Церемония (Cargo.toml, версии) | Средняя | Минимум | Высокая | Минимум |
| Соответствие research-консенсусу | «5–7 норма» | Ниже | «дальше не дробить» нарушено | Встречается, реже |
| Переезд при росте | Не нужен | B→A: вынос модулей, средне | C→A: слияние, средне | D→A: переезд всего |

**Lean автора — A**: совпадает с ответом владельца (Q1-а), research-консенсусом и живыми примерами; B экономит церемонию сейчас ценой границ, которые важны именно из-за агентов-коммиттеров; C нарушает «дальше не дробить»; D — отказ от решения.

## Explicitly not considered

- **cargo-hakari/workspace-hack** — выигрыш околонулевой на 6 крейтах (research).
- **nx/Turborepo/Bazel-класс** — кэш графа JS-пакетов/эрметичная сборка ради одного фронта и cargo-кэша; третий инструмент без выигрыша (подтверждено владельцем, Q5).
- **Отдельные репозитории** (фронт/образ исполнителя/доки) — против «один PR меняет пин CLI и тесты вместе» (Q7) и против единого источника истины.
- **Bun workspaces** — один JS-пакет, нечего оркестрировать.
- **just + mise одновременно** — гарантированный дрейф (research); выбран один раннер.
- **rust-embed как основа** — жив, но static-serve покрывает сжатие/кэш из коробки; остаётся запасным (40-строчный handler).
