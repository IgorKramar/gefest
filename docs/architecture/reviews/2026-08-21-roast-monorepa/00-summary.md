# Roast: monorepa-decision (D-17)

**Target**: `docs/architecture/research/2026-08-21-monorepa-decision.md`
**Date**: 2026-08-21
**Roles run**: devil-advocate (B-N), pragmatist (H-N), junior-engineer (J-N), compliance-officer (C-N), futurist (F-N)

## Headline findings

- **Devil-advocate**: агент-коммиттер физически не может перегенерировать `.sqlx` — «сторож за агентами» ловит невозможность, не забывчивость (B-1); path-фильтры оставляют корневой Cargo.toml, `.sqlx/**` и `infra/**` вообще без CI (B-2, B-3); кэш chef греет GHA, а образ собирается на холодной прод-VM рядом с живыми сессиями (B-8).
- **Pragmatist**: скелет — 15–25 ч, не «первый PR»; embed-налог bun-сборки на каждую Rust-итерацию всех коммиттеров (H-2); красный `prepare --check` пейджит владельца 3–5 раз в неделю на фазе GF-5 (H-3).
- **Junior-engineer**: «пустой dist валит громко» — требование без механизма (J-1); граф записан двумя противоположными нотациями стрелок (J-2); триггеры contract-job противоречат сами себе (J-6).
- **Compliance-officer**: `.dockerignore` не исключает `.env`, `.git` и ключи при контексте от корня и сборке на прод-VM (C-1); supply chain пинован выборочно — экшены GHA не по SHA (C-4).
- **Futurist**: `api` — единственный крейт без верхней границы, всё новое падает в него (F-1); правило «core только типы» не переживёт год без CI-сторожа (F-2); static-serve — самая хрупкая зависимость (F-7).

## Cross-cutting concerns

- **CC-1. sqlx-цикл агента** (B-1, H-3): источник закрытия уже в конституции — комплект брокера ADR-0006 включает чистую dev-БД клоном шаблона; для задач над репо Гефеста шаблон несёт схему Гефеста с накатанными миграциями, задача `mise sqlx-prepare` берёт DSN из комплекта. До готовности брокера (GF-2) — интерим-регламент: «SQL-запросы меняет владелец»; runbook красного `prepare --check` — в README крейта `db`.
- **CC-2. Слепые зоны и противоречия path-фильтров** (B-2, B-3, B-4, J-6, F-5): фильтры пересобираются: rust-job дополнительно триггерится на корневые `Cargo.toml`/`Cargo.lock`/`.sqlx/**`; contract-job = `tests/contract/**` + `crates/runner/**` + `crates/fake-executor/**` + `crates/core/**` + `infra/executor-image/**` (закрывает ворота CC-8 ADR-0009 конструкцией); infra-job (сборка образа без пуша) на `infra/**`; required-совместимость — фильтрация внутри job-а (job стартует всегда, решает по diff), не skip снаружи; nightly/merge-queue — полный прогон без фильтров; правило «новый верхнеуровневый каталог = правка фильтров тем же PR».
- **CC-3. Embed-налог и порядок сборки** (B-7, H-2): feature-флаг `embed-static` — в dev/test/rust-job выключен (`api` собирается без dist), включён в docker-job и релизе; порядок bun→cargo — зависимостью mise-задач, не параллелью; web-правки компилируют `api` с embed в merge-queue/nightly (зелёный CI ≠ красный деплой).
- **CC-4. Сборка образа не на прод-VM** (B-8, C-6): CI собирает прод-образ и пушит в приватный GHCR; `deploy.sh` = `docker compose pull && up -d` — линковка не конкурирует с живыми сессиями, кэш chef работает там, где он есть. Уточняет деталь ADR-0012 (ручной деплой остаётся — меняется способ получения образа); registry назван (закрывает и «где хранится» C-6).
- **CC-5. Дом типов stream-json** (B-5): типы — в `core` (чистые serde), но контракт работает на сырых байтах: `fake-executor` эмитит литеральные JSONL-фикстуры (включая невалидные и «exit 0 без result»), общие типы разрешены только для сборки фикстур; кейсы порчи — строками, не структурами.
- **CC-6. core против sqlx-derive** (B-6, F-2): `sqlx` в `core` — optional feature (default пуст), включает только `db`; чистота `core` = дефолтный граф без рантаймов, CI-сторож `cargo tree -p core` (без фич) на tokio/axum/sqlx; чистые переходы машин состояний в `core` разрешены явно.
- **CC-7. Секреты и supply chain** (C-1, C-2, C-4, C-6, H-5): `.dockerignore` расширен (`.git/`, `.env*`, `reference/`, `docs/`, ключевые маски); секреты сборки — только `--mount=type=secret`; `.gitignore` с `.env*` — в скелете, граница «в `.env` только локальный dev-DSN»; `Cargo.lock` в git; версии точные, единый источник — `mise.toml` (оттуда же CI); экшены GHA — по SHA (прецедент CVE-2025-30066); образы без кредов в слоях; `cargo deny check licenses` — отложено записью «до причины распространения».
- **CC-8. Фазировка скелета** (H-1, H-4, «What's actually realistic»): три PR — (1) workspace + пустые крейты + `mise.toml` + CI + `rust-toolchain`-пин + runbook; (2) dev-контур (vite-прокси на API, bacon, флаг `embed-static`); (3) Dockerfile+chef+GHCR (= GF-6). Bootstrap ворот — в два приёма (checks появляются после первого прогона — ожидаемо); зависимости добавляет владелец отдельным PR первым в очереди (merge train).
- **CC-9. Текст решения** (J-1…J-8): механизм «валит громко» назван (проверка в `build.rs` крейта `api`; поведение static-serve уточнить при внедрении); нотация графа — единая «→ = зависит от»; sqlx#3836 с придаточным; суть ловушки edition 2024 + минимум-список `default-features = false`; фичи sqlx перечислены; ссылки на файлы цикла в шапке; легенда дополнена («дверь», «перечисления-истина»); «~10 мин» уточнено (холодная CI-пересборка).
- **CC-10. Старение** (F-1, F-3, F-4, F-6, F-7, F-8): `api` модулен по доменам (documents/chat/mcp/views) с первого дня, распухший модуль — кандидат в седьмой крейт; TS-типы — только генерацией из Rust со сторожем (принцип сейчас, генератор при открытии двери); дверь `hef remote` — «не тянет server-фичи»; раскладка «куда класть код» — в одном каноническом файле; static-serve/chef — границы пересмотра уже названы в §4, дополнены сигналами futurist.

## What survived

Выбор A не оспорен ни одной ролью: шестёрка крейтов, `crates/*`+`web/`+`infra/`, mise tasks, `.sqlx`-сторож как идиома, линейный граф, edition 2024 + workspace-наследование, границы пересмотра событиями — «стареет предсказуемо». Атаки бьют по деталям CI/сборки/деплоя и по несостыковкам с уже принятыми ADR, не по форме workspace.

## Recommended path

**Apply and proceed** — 37 находок закрываются ред. 2 (CC-1 sqlx-цикл агента и CC-2 фильтры — главные содержательные правки; CC-4 меняет способ доставки образа на VM). Re-roast не требуется: правки уточняют конструкцию внутри выбранной раскладки. Владельцу на подтверждение: (1) **CC-4** — прод-образ собирает CI и пушит в приватный GHCR, `deploy.sh` делает pull (уточнение детали ADR-0012); (2) **CC-1-интерим** — до готовности брокера SQL-запросы меняет только владелец; (3) **CC-3** — feature-флаг `embed-static` (dev/CI без фронт-сборки, полный embed в docker-job/merge-queue).
