# GF-8: вывод данных из Supabase — миграция + удаление проекта

- Статус: backlog (D-14; ADR light — при исполнении)
- Фаза: Ф1, срок — до конца Ф1

Задача-владелец для D-14. Заводится потому, что «до конца Ф1» без владельца — ровно тот пассивный триггер, против которого направлена находка F-1: «Триггер без календарной задачи — пожелание, не граница» (`docs/architecture/reviews/2026-08-20-roast-konsolidaciya-orkestracii-agentov/05-futurist.md:18`; далее — файлы того же каталога). Наблюдение O-3 (`../architecture/research/2026-08-20-observe.md`) прямо требовало завести GF-задачу с дедлайном.

**Что закрывает.** Supabase (Ирландия) держит журнал, документы vault (контекст клиентских проектов, карточки людей — ПД третьих лиц) и статусы. Экспозиция по C-5: конфиденциальность перед клиентами; 152-ФЗ при квалификации карточек как обработки ПД вне «личных нужд»; риск одностороннего отключения ЕС-облака (`04-compliance-officer.md:49`). Целевое состояние задано ADR-0010: данные — на российской VM. Free tier держит бэкапы максимум 7 дней (`02-pragmatist.md:32`), поэтому удаление проекта — часть работы, а не следствие: пока проект жив, живы и копии у вендора.

**Состав.** (1) Инвентаризация фактического содержимого — compliance-роль отметила её как непроверенное место (`04-compliance-officer.md:70`); (2) миграция в свой Postgres в compose — только событиями `imported`, как предписывает cutover-правило ADR-0005; (3) сверка контента после переноса; (4) удаление проекта Supabase (закрывает бэкапы вендора); (5) снятие остаточных ссылок и кредов из конфигурации и каталога ресурсов.

**Интерим до исполнения** (C-5): состав уезжающих в Supabase данных не расширяется — в первую очередь туда не добавляются диалоги сессий.

**Контрольная точка.** Если к квартальной ревизии GF-4 (первая — до 2026-11-20) фаза Ф1 не закрыта, срок пересматривается там явно, с записью исхода. Молчаливый перенос срока не допускается — «переезд будет гореть сроком, пересмотр не случится» (`05-futurist.md:47`).

Готово = данные перенесены и сверены + проект Supabase удалён + ссылок и кредов на него в конфигурации не осталось + запись в `docs/architecture/` (ADR light либо строка в decision-map с исходом).
