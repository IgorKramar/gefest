# GF-2: Ф0 — раннер-супервизор

- Статус: backlog (ADR-0007 принят — можно брать)
- Фаза: Ф0

Первый компонент Гефеста с нуля: порождение и возобновление `claude -p --resume` (stream-json), инкрементальная запись событий в Postgres (не батчем — анти-урок yao), состояние `delivered` подтверждаемо, идемпотентность по ключу задачи (одна задача — одна живая сессия), переподхват живых сессий при рестарте раннера, «прервано» ≠ «завершено».

Ядро v1 по ADR-0007 §5 (70 %-фазировка, 4–6 недель темпа): writer stdin per-сессия (сериализация с SIGTERM), каузальный наблюдатель delivered (S5), SIGTERM-обвязка с синтетическим закрытием и `cancelled_by_stop`, reconciliation с дедупом по uuid, **фальшивый исполнитель** для тестов, поле «почему стоит» + лог решений планировщика, планировщик v1 (потолок 5 + ручной слот + FIFO), один авто-ретрай, алерт «sent без delivered > N сек». Итерация 2 — пер-ролевые квоты, приоритеты, типология сбоев, стоп-по-таймауту, requires_ack-код. Артефакты GF-2: типология сбоев, итоговый список исходов доставки (в границах «не уже ADR-0005»).

Готово = мерж + зелёная проверка + DoD Ф0 из decision ред. 2 (команда доходит до агента с `delivered`; гашение отражается как прерывание; рестарт раннера не теряет и не дублирует сессии).
