# DeepSeek Harness (DSH) — обзор

Собрано 2026-08-20 из официального сайта, документации и обзоров. Срез знаний модели этот релиз не покрывает — всё ниже проверялось по источникам.

## Что это

**DeepSeek Harness (`dsh`)** — открытый агентный рантайм от DeepSeek. Выпущен 13.08.2026, лицензия MIT, статус — developer preview (на момент записи v0.1.0-rc.6). Концепция: **Agent = Model + Harness** — модель это «душа» агента, harness даёт ему окружение, инструменты и работу в реальных условиях.

Ключевой принцип: **всё — плагин**. Модели, инструменты, skills, сессии, песочницы, хранилище, планировщик, UI и даже главный агентный цикл — сменные компоненты, заменяемые конфигурацией без правки исходников.

## Архитектура (верхний уровень)

- Ядро — **Cordis** (мета-фреймворк плагинов, см. https://github.com/cordiverse/paper): отвечает только за загрузку/выгрузку плагинов и разрешение зависимостей.
- Плагины взаимодействуют через **сервисы** и **события** Cordis.
- **Трассировка**: всё, что видит модель (системные промпты, рассуждения, вызовы инструментов, результаты), пишется в append-only журнал сессии; на одном потоке событий работают resume, ветвление, поиск и replay.

## Профили (режимы)

Профиль — bundled-набор плагинов; определяет, что доступно сессии.

| Профиль | Состав |
| --- | --- |
| **Standard** | полный набор: правка файлов, shell, веб-поиск, skills, планы, подагенты |
| **Code (PTC)** | агент генерирует TypeScript для оркестрации множества вызовов инструментов |
| **Minimal** | только bash и редактор — для бенчмарков |
| **Creator** | инспекция рантайма, тестирование плагинов, создание собственных режимов |
| **web** | профиль за Web UI — именно в него ставятся пользовательские плагины |

## Быстрый старт

Требуется Node.js ≥ 22.19.

```bash
npx @deepseek-ai/dsh web        # Web UI на http://127.0.0.1:3080, данные локально
```

Далее: Settings → Models → API-ключ DeepSeek → Choose workspace → первая задача.

## Масштаб проекта

GitHub: ~169k звёзд, ~18k форков, ~13k коммитов, монорепа на pnpm workspace (apps/, packages/, native/, python/, docs/, examples/, website/). Есть Python SDK. Breaking changes между rc-версиями объявлены нормой — **пиновать версии обязательно**.
