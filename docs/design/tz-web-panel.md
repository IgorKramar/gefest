# ТЗ: веб-панель Гефеста

Норматив для макетов (Claude Design). Основание: ADR-0015 и вся серия ADR-0001…0014. Язык интерфейса — русский. Один пользователь — владелец (Игорь); второй оператор — будущая дверь, в макетах не отражается.

## 1. Контекст продукта

**Гефест** — self-hosted оркестратор команды LLM-агентов (Claude Code). Владелец ставит задачи, агенты работают в изолированных контейнерах; панель — единственный интерфейс: живые статусы, доставка указаний с гарантиями, чат агентов, подтверждения решений, каталог ресурсов, журнал. Главные боли, которые панель лечит: «не вижу, чем заняты агенты прямо сейчас» и «команда отправлена, но не дошла». Панель открыта весь рабочий день на втором мониторе — это операторский пульт, не витрина.

**Пользователь:** технический, работает с кодом, ценит плотность информации и моноширинную точность; читает быстро, интерфейс не должен объяснять сам себя маркетинговыми словами.

## 2. Характер и принципы

**«Тёмная кузница»** — сдержанная индустриальная база с огненными акцентами. Гефест — кузнец с автоматонами: метафора живёт в деталях (иконография, пустые состояния, формулировки), а не в декоре. Принципы:

- **Пульт, не дашборд-витрина**: данные первичны, украшения не конкурируют с ними; никакой график не рисуется «для красоты».
- **Огонь = работа**: янтарно-оранжевая шкала зарезервирована за активностью агентов; она не используется для декора, поэтому взгляд мгновенно находит «кто куёт».
- **Состояние всегда названо**: цвет никогда не единственный носитель смысла — рядом слово или иконка (доступность + однозначность).
- **Тишина — хорошее состояние**: когда всё спокойно, панель выглядит спокойно; тревожные элементы (алерты, «почему стоит», непрочитанное) появляются только по делу.
- **Моно — язык фактов**: ключи задач, ID, команды, время, счётчики — JetBrains Mono; прозаический текст — никогда моно.

## 3. Токены

### 3.1 Цвет (oklch)

| bg-1 | oklch(0.19 0.014 50) | карточки, панели |
| bg-2 | oklch(0.23 0.015 50) | приподнятые поверхности, ховеры |
| border | oklch(0.30 0.015 50) | границы, разделители |
| border-strong | oklch(0.40 0.02 50) | границы фокусных элементов |
| text-1 | oklch(0.93 0.005 60) | основной текст |
| text-2 | oklch(0.70 0.010 60) | вторичный |
| text-3 | oklch(0.53 0.010 60) | подписи, disabled |
| accent | oklch(0.72 0.17 55) | огонь: главный акцент, primary-кнопки, активная навигация |
| accent-hover | oklch(0.76 0.18 55) | ховер акцента |
| accent-subtle | oklch(0.30 0.06 55) | огненная подложка (бейджи, выделение строки) |

**Статусная шкала** (единые светлота/хрома внутри семейства — различие только хьюем; тёмная тема):

| Статус | Цвет | Смысл |
|---|---|---|
| running | oklch(0.72 0.17 55) — огонь | агент работает (совпадает с accent намеренно) |
| waiting_answer | oklch(0.75 0.15 90) — жёлтый | ждёт ответа владельца |
| sleeping | oklch(0.65 0.05 250) — остывшая сталь | спит/пауза |
| completed | oklch(0.70 0.13 150) — зелёный | завершено |
| failed / interrupted | oklch(0.63 0.19 25) — раскалённый красный | сбой / прервано |
| queued / idle | oklch(0.60 0.02 60) — нейтральный | в очереди, нет сессии |

**Светлая тема, «остывший металл»**: bg-0 oklch(0.97 0.004 75), bg-1 oklch(0.995 0.002 75), bg-2 oklch(0.94 0.006 75), border oklch(0.87 0.008 75), text-1 oklch(0.24 0.012 60), text-2 oklch(0.45 0.012 60), text-3 oklch(0.60 0.010 60); accent oklch(0.60 0.14 55) (приглушён на ступень); статусные — светлота 0.55–0.62 при той же логике хьюев. Переключатель: тёмная/светлая/системная.

Семантические статусы всегда через токены (никаких сырых hex в макетах); фокус-кольцо — accent 2px со смещением 2px.

### 3.2 Типографика

Tektur (variable: wght 400–900, wdth) — только заголовки и крупные числа пульта. Golos Text (wght 400–900) — весь UI-текст. JetBrains Mono (wght 100–800) — данные. Все self-hosted.

| Уровень | Comfortable | Compact | Шрифт |
|---|---|---|---|
| h1 (заголовок страницы) | 28/34 · 700 | 24/30 · 700 | Tektur |
| h2 (секция) | 20/26 · 600 | 18/24 · 600 | Tektur |
| h3 (карточка) | 16/22 · 600 | 15/20 · 600 | Golos |
| body | 14/21 · 400 | 13/19 · 400 | Golos |
| small | 12.5/17 · 400 | 12/16 · 400 | Golos |
| mono | 13/19 · 450 | 12.5/17 · 450 | JetBrains Mono |
| mono-small (псевдотерминал) | 12/17 · 400 | 11.5/16 · 400 | JetBrains Mono |

### 3.3 Пространство, форма

- Шаг отступов: comfortable — 4/8/12/16/24/32/48; compact — 2/4/8/10/14/20/32.
- Радиусы (гранёная «кузница», без скруглённого дружелюбия): карточки 8, контролы 5, бейджи/чипы 3. Compact: 6/4/2.
- Тени минимальны; глубина — цветом поверхности (bg-0→bg-2) и границей. В тёмной теме допустим тонкий огненный glow только у активно работающих элементов (карточка running-агента: 1px border статусного цвета + свечение 0 0 12px с альфой 15%).
- Контролы: высота 36 (comfortable) / 30 (compact); поля ввода той же сетки.

### 3.4 Иконография

Инлайн-SVG, stroke 1.5px, сетка 20 (в тексте 16, на пульте 24). Единый комплект. Никаких эмодзи как иконок. Характерные доменные иконки: молот (задача в работе), наковальня (доска), автоматон (агент), горн (пульт/активность), свиток (журнал), клеймо (решения/подтверждения), связка ключей (ресурсы), мехи (настройки). Статусные глифы: пламя (running), песочные часы (waiting), полумесяц (sleeping), клеймо-галочка (completed), трещина (failed).

## 4. Каркас

- **Левый сайдбар**, ширина 232 (comfortable) / 200 (compact), сворачивается до 56 (иконки + тултипы). Порядок: Доска задач · Агенты · Чат · Решения · Журнал · Ресурсы · Документы · Настройки. Активный раздел — огненная вертикальная метка 2px + accent-текст. Бейджи непрочитанного: Чат, Решения (моно-счётчик). Низ сайдбара: переключатель темы, плотности, свёртка.
- **Глобальная шапка** (на всех страницах): слева заголовок страницы (Tektur), справа — **мини-пульт**: горизонтальный ряд фишек агентов (аватар-глиф роли + статусная точка), по клику — переход к агенту; правее — глобальный индикатор алертов и меню владельца.
- **Раздел «Документы»** присутствует в навигации с состоянием «скоро» (Ф2) — место резервируется, пункт полупрозрачен.
- Минимальная ширина макета — 1200; сайдбар авто-сворачивается ниже 1360.

## 5. Экраны

Для каждого экрана обязательны состояния: **загрузка** (скелетоны той же геометрии), **пусто** (иллюстрация-глиф + одна фраза с характером + одно действие), **ошибка** (что случилось + повторить), **реконнект** — глобальный баннер «Связь восстановлена — догоняем журнал…» при gap-detection (ADR-0005).

### 5.1 Доска задач (главная)

- Колонки по статусам (v1: Бэклог · В работе · Ждёт · Готово); Jira-класс (эпики, спринты) — не рисовать, дверь D-15.
- Карточка задачи: ключ (mono, `GF-12`), заголовок (body, 2 строки макс.), роль-исполнитель (глиф+имя), статусная точка живой сессии, бейдж «почему стоит» (если стоит), индикатор непрочитанных вопросов. Плотный режим — строки таблицы вместо карточек.
- Фильтр по проекту (селект с ключами-моно), поиск.
- Виджет детекторов расхождений — зарезервированное место над колонками (v1 — скрыт).
- Действия карточки: открыть задачу (боковая панель-детализация: описание, события, сессии, команды с трассой), стоп, передать.

### 5.2 Агенты (пульт)

- Сетка карточек агентов-ролей (comfortable) / плотная таблица (compact).
- **Карточка агента** (доменный компонент, анатомия): шапка — глиф роли + имя + статус (слово+цвет); строка текущей задачи (ключ моно + заголовок); **последняя веха** («Bash: cargo test · 40 с» — mono-small, живо обновляется); **мини-лента** последних 3–5 вех (иконка типа + краткое резюме + относительное время); **псевдотерминальная строка** — однострочный бегущий прогресс из вех на bg-0 (mono-small, огненный курсор-блок); бейдж «почему стоит» (quota/limit/probe/sleeping — жёлтая подложка, слово); футер — кнопки: Стоп (danger-ghost), Указание (primary-ghost), Вопросы (если ждёт — жёлтая primary).
- running-карточка получает огненный glow (см. 3.3); спящие приглушены (никогда не исчезают).
- Клик — страница сессии.

### 5.3 Сессия (детализация)

- Шапка: роль, задача, статус, «родословная» (цепочка parent_session_id — хлебные крошки ретраев).
- **Лента вех** (таймлайн): границы ходов — крупные узлы, tool-вызовы — компактные строки (иконка + имя инструмента + длительность + статус); вопросы — жёлтые узлы с текстом; interrupted/limit — красные/жёлтые метки. У границ ходов — кнопка **«Показать диалог»** → модальный просмотр среза сырья (моно, тёмный фон всегда, копирование; состояние «Сырьё истекло» после 30 дней — глиф + саммари рядом).
- Панель саммари (последнее саммари исполнителя; пометка «саммари отсутствует» при summary_missing).
- Трасса команд этой сессии (см. компонент «Трасса доставки»).

### 5.4 Чат

- Один канал (комнаты — дверь, не рисовать). Лента сообщений: автор (глиф роли/владелец), время, текст; **сообщения владельца** — огненная левая метка и чуть выделенная подложка (агенты разбирают их первыми — визуально это видно).
- Индикация «доставлено ≠ прочитано»: у сообщения — счётчик прочитавших агентов (по курсорам), деталь по ховеру.
- Композер: поле + переключатель **«Как сообщение / Как указание»** (указание — с выбором адресата и огненной кнопкой «Отправить с гарантией» — уходит в машину доставки ADR-0007).
- Пустое состояние: «В кузне тихо. Агенты пишут сюда, когда координируются.»

### 5.5 Решения

- **Единая очередь** карточек: четыре pending-потока (кандидаты памяти · предложения ресурсов · канон документов · передача работы) + вопросы агентов. Фильтр-чипы по типу; сортировка по возрасту.
- **Карточка решения** (анатомия): тип (глиф+слово, клеймо), автор-агент, контекст (задача/ссылка), содержимое (текст предложения / вопрос, сворачиваемое), возраст (моно; после порога эскалации — жёлтый), действия: **Принять** (primary), **Отклонить** (ghost), поле комментария; для вопросов — поле ответа + «Ответить» (ответ уходит указанием).
- Пустое состояние: «Всё расклёпано. Новые решения появятся здесь.»

### 5.6 Журнал

- Лента событий (журнал ADR-0005: вопросы/блоки/закрытия/заметки + импортированные), фильтры по виду и актору, поиск (русский FTS).
- Строка события: время (моно), актор, вид (глиф), текст; блоки — с индикатором «снят/висит».
- Место под фильтр «Расхождения» (детекторы, Ф1) — зарезервировано.

### 5.7 Ресурсы

- Три вкладки: **Каталог** (креды/env/живые сервисы: имя, тип, скоуп, кому выдан — таблица), **Пул токенов** (остаток, сроки истечения — прогресс-полосы; жёлтый алерт «пополни пул»), **Секреты** (CRUD владельца; значения скрыты, показ по клику с аудит-отметкой).
- Предложения агентов («агент просит ресурс») всплывают и здесь, и в Решениях.
- Каждая выдача — след (кому/когда/какой задаче) — разворачиваемая история.

### 5.8 Настройки

Темы, плотность, каналы алертов (Telegram/ntfy/почта — статус каждого, тест-кнопка), passkeys (список устройств, «добавить устройство» — одноразовая ссылка), пороги (эскалация непрочитанного, delivery_confirm_timeout — просто числовые поля с описаниями), лимит-окна (просмотр состояния 5h/weekly).

## 6. Доменные компоненты (сводно)

1. **КарточкаАгента** — см. 5.2.
2. **ТрассаДоставки** — горизонтальная цепочка чипов состояния указания: queued → sent → delivered (каждый — время в моно; активный — огонь); терминальные ветки: cancelled_by_stop (серый, перечёркнутый глиф), limit_blocked (жёлтый); при requires_ack в будущем — место под чип ack. Ховер — полная история command_deliveries.
3. **БейджПочемуСтоит** — жёлтая подложка + слово (квота/лимит/проба/сон) + деталь по ховеру («роль kst: 2/2 заняты GF-7, GF-9»).
4. **ЛентаВех / Псевдотерминал** — см. 5.2/5.3.
5. **ОчередьРешений / КарточкаРешения** — см. 5.5.
6. **МиниПульт** — шапочный ряд статус-фишек (см. 4).
7. **ИндикаторПрочитанности** — точки/счётчик по курсорам читателей.

## 7. Движение

Сдержанное: статусные переходы — 150 мс crossfade цвета; появление вех в ленте — 200 мс fade+2px slide; огненный курсор псевдотерминала — мягкий блинк 1.2 с; view transitions (same-document) на переходах разделов — 200 мс. Никаких «летающих» карточек, конфетти, пружин. prefers-reduced-motion уважается (всё до 0).

## 8. Доступность и клавиатура

Контраст текста ≥ 4.5:1 в обеих темах (огненный accent на bg-0/bg-1 — проверен на 3:1+ для крупного/жирного, для мелкого текста на подложках использовать text-1); цвет+слово всегда вместе; полная клавиатурная навигация (Base UI-примитивы); фокус-кольца видимы; команд-палитра ⌘K (переход к агенту/задаче/разделу) — желательна, зарезервировать в шапке.

## 9. Чего НЕ делать

Без градиентных фонов-месива; без эмодзи в иконках и текстах интерфейса; без «карточек с закруглением 16 и левой цветной полосой» как универсального паттерна; без Inter/Roboto/Arial; без пустых декоративных графиков и «данных-слопа» (числа только осмысленные); без светящегося неона повсюду — огонь дозирован (см. принцип «огонь = работа»); без англицизмов в UI-текстах, где есть русское слово; заглушки реальных значений — видимые плейсхолдеры (`[ХОСТ]`), не выдуманные данные.
